## Qualification and compatibility

Source commands and their exact prerequisite/consumer closure are documented in
[setup](setup.md). They run only after a check grant. The source link check reads
current files and prepared routing metadata without network or browser activity;
it cannot qualify remote links, fragments, private evidence or distribution
rights. Retained benchmark/test drivers are excluded from this metadata check.

A release needs the exact source commit, archive hash/size/full file map, declared
exports or document destinations, common CI receipts, independent installed
consumer evidence and complete publication-ref audit. Actual app adoption and
public artifact transport are additional gates. Do not relabel older source-only
receipts as checks at the new paths. Preserve changed receipts before resealing.

Rollback keeps original source revision/blob maps, prior archives and ignored
evidence. Revert only the reviewed source increment; do not reset/clean archives
or erase another owner's dirty work. A reverted helper/import invalidates its
new consumer receipt. Historical measurements remain historical after rollback.

It marks every runtime as unqualified. `scripts/lib/browserHost.ts` is the actual explicit host contract; fixtures require one SettingsRegistry, camera input/frame/clock ports, renderer bootstrap and raster loader/device/lighting ports. The image control adapter consumes public cubemap/equirectangular uploader adapters plus the same renderer queue and host image broker/scope. Their runnable entrypoints fail explicitly rather than read old app internals; byte-exact originals remain inert `.mjs.txt` evidence in `fixtures/legacy-source/`. These blockers cannot be solved by copying Flight implementations into Earth.

CPU/GPU experiments, local HTTP experiment servers and headless browser launches require a coordinator grant separately from source checks. Public format basis imports may change floating-point work/cost; no retained image-representation timing result is requalified. Synthetic pattern tools remain experimental algorithms rather than accepted delivery formats.

Output defaults use owner `build/` dated runs. `--results`, `--out` and direct result overrides are bounded to that owner where adapted; legacy model-only helpers write through those wrappers. Retained record folders are read inputs, never automatic cleanup targets. A browser that fails to exit naturally leaves the operation pending for explicit external handling, not a fabricated completed shutdown.
