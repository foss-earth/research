# Superseded: Gamepad Tools

The current product is **gamepad-tools**: an independently written Babylon.js/WebGPU-first live controller viewer and keyboard/gamepad action-binding utility for foss-earth and 0sfs. The 3D viewer is optional.

Read [Gamepad Tools research and host integration](gamepad-tools-research.md) and the [implementation handoff](gamepad-tools-agent-prompt.md).

The old Gamepad Studio fork and full diagnostic-studio scope are superseded. The user deleted that repository. The independent repository is [Felipegalind0/gamepad-tools](https://github.com/Felipegalind0/gamepad-tools).
